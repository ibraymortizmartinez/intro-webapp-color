# 🟦 COLOR_EXTRACTOR_SYS v3.0.42
> **STATUS:** SYSTEM_OPTIMAL | **CORE:** NEON_ENGINE | **OPERATOR:** HUMAN_AUTHORIZED

`COLOR_EXTRACTOR` es una herramienta avanzada de análisis y manipulación cromática con una interfaz de usuario de alta fidelidad inspirada en la estética Cyberpunk. Permite a los desarrolladores y diseñadores extraer códigos hexadecimales, mapear valores RGB/HSL y generar armonías de color en tiempo real a través de un entorno de ejecución fluido.

---

## 🛠 ESPECIFICACIONES TÉCNICAS (CORE_FEATURES)

### 1. Extracción Cromática de Precisión
* **Manipulación Dinámica**: Control granular de canales **R_G_B** mediante sliders de respuesta inmediata.
* **Visualizador Diamante**: Previsualización central con efectos de post-procesamiento (scanlines y glow).
* **Conversión Instantánea**: Generación automática de mapas **HEX**, **RGB** y **HSL**.

### 2. Generador de Armonías (PALETTES)
* Algoritmo integrado para el cálculo de colores **Complementarios** y **Análogos**.
* Acceso rápido a paletas mediante interacción directa con swatches técnicos.

### 3. Interfaz de Usuario (UX/UI)
* **Bento Grid Layout**: Organización modular de componentes para una visualización clara de datos.
* **Sistema de Notificaciones**: Alertas de terminal en tiempo real que confirman las acciones del sistema.
* **Reloj de Sistema y Uptime**: Monitorización persistente de la sesión de trabajo.

---

## 🚀 INSTALACIÓN Y DESPLIEGUE

Para inicializar el entorno local de **COLOR_EXTRACTOR**, siga estos protocolos:

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/tu-usuario/color-extractor.git](https://github.com/tu-usuario/color-extractor.git)
    ```
2.  **Navegar al directorio:**
    ```bash
    cd color-extractor
    ```
3.  **Ejecutar mediante Live Server:**
    Abra `index.html` en su navegador preferido (Se recomienda Chrome o Edge para efectos de renderizado óptimos).
